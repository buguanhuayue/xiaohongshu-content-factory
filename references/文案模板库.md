# 小红书爆款文案模板库

> 直接套用，替换关键词即可快速生成笔记。

---

## 一、干货清单型

### 模板1：数字清单

```
【标题】[数字]个[领域]技巧/误区/方法

[开头] 痛点共鸣 + 身份认同
"是不是也有这样的困扰..."
"作为[身份]，我深有体会..."

[主体] 分点论述
✅ [要点1]：简短解释
✅ [要点2]：简短解释
✅ [要点3]：简短解释
...

[结尾] 总结 + 互动
"坚持[时间]，[效果]肉眼可见！"
"觉得有用收藏起来，下次用得到~"
```

### 模板2：步骤教程

```
【标题】[效果]步骤/教程/方法

[开头] 效果承诺 + 身份
"学会这个方法，[效果]！"
"新手也能轻松上手..."

[主体] 分步骤
📌 步骤1：[动作] + [要点]
📌 步骤2：[动作] + [要点]
📌 步骤3：[动作] + [要点]

[结尾] 鼓励 + 互动
"试试看，你会回来感谢我的"
"有什么问题评论区问我"
```

## 二、对比型

### 模板3：前后对比

```
【标题】[时间]前后对比 / [方法]真的有用吗

[开头] 痛点 + 尝试
"被[问题]困扰了很久..."
"终于下定决心试试[方法]..."

[主体] 对比展示
❌ 之前：[问题描述]
✅ 现在：[改善描述]
💡 方法：[具体做法]

[结尾] 鼓励 + 建议
"坚持就是胜利！"
"希望对你也有帮助"
```

### 模板4：产品对比

```
【标题】[A产品] vs [B产品] / 到底选哪个

[开头] 选择困难
"最近很多姐妹问我[A]和[B]怎么选..."
"两款都用过，说说真实感受..."

[主体] 对比维度
| 维度 | A产品 | B产品 |
|------|-------|-------|
| 价格 | ... | ... |
| 效果 | ... | ... |
| 适合 | ... | ... |

[结尾] 个人建议
"我个人更推荐[选择]，因为..."
"根据自己情况选择"
```

## 八、标签模板

### 核心标签（必带）
- #[领域] 如 #护肤 #穿搭 #美食
- #[领域]分享 如 #护肤分享 #穿搭分享
- #[领域]日常 如 #护肤日常 #穿搭日常

### 长尾标签（精准）
- #[领域][细分] 如 #油皮护肤 #小个子穿搭
- #[领域]推荐 如 #护肤推荐 #穿搭推荐
- #[领域]攻略 如 #护肤攻略 #穿搭攻略

### 热点标签（蹭流量）
- 当前热门话题标签
- 节日/季节标签
- 流行趋势标签

### 地域标签（可选）
- #[城市][领域] 如 #北京护肤 #上海穿搭
- #[城市]生活 如 #北京生活 #上海生活

## 九、emoji 使用规范

### 常用 emoji 含义

| Emoji | 含义 | 使用场景 |
|-------|------|----------|
| ✅ | 正确/推荐 | 正面要点 |
| ❌ | 错误/避免 | 负面要点 |
| ⚠️ | 注意/警告 | 注意事项 |
| 💡 | 提示/建议 | 小贴士 |
| ⭐ | 推荐/重点 | 重点内容 |
| 🔥 | 热门/推荐 | 热门内容 |
| 📌 | 固定/要点 | 要点标记 |
| 1️⃣2️⃣3️⃣ | 序号 | 分点编号 |
| 🌟 | 亮点 | 优点展示 |
| 💰 | 省钱/价格 | 价格相关 |
| ⏰ | 时间 | 时间相关 |
| 📝 | 记录/笔记 | 记录相关 |

### emoji 使用原则
- 每段 1-2 个，不超过 3 个
- 用于分隔、标记，不堆砌
- 与内容语义匹配
- 避免在标题中过度使用

## 十、快速生成流程

1. **确定赛道** → 选择对应模板
2. **确定选题** → 套用标题公式
3. **撰写正文** → 按模板填充内容
4. **添加标签** → 核心+长尾+热点
5. **检查敏感词** → 对照敏感词清单
6. **优化排版** → emoji + 分段 + 重点
7. **保存发布** → 整理成素材包
