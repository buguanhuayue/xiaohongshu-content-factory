## 🚀 功能介绍

### 全流程自动化

| 阶段 | 输入 | 输出 |
|------|------|------|
| 📊 **选题策划** | 领域/赛道 | 热点追踪 + 竞品分析 + 3-5 个备选选题 + 爆款潜力评估 |
| ✍️ **文案撰写** | 确认的选题 | 5 个备选标题 + 300-800 字小红书风正文 + 5-10 个标签 + 互动引导语 |
| 🎨 **配图设计** | 文案内容 | 封面图 MJ/SD 提示词（≥2 套） + 内页图方案 + 排版建议 |
| 📐 **排版优化** | 完整素材 | 格式调整 + 敏感词检查 + 可直接复制到小红书的终稿 |
| 📅 **发布排期** | 发布素材 | 最佳发布时间 + 完整发布素材包文件 + 数据追踪建议 |

### 三大核心能力

**1. 热点雷达**
自动追踪小红书、微博、知乎等平台热点，帮你抢占流量窗口。结合竞品高赞笔记拆解，找到"有爆款相"的选题。

**2. 文案工厂**
12 套经过验证的文案模板（干货清单、对比测评、经验分享、逆袭故事...），覆盖护肤、穿搭、美食、职场、健身等主流赛道。标题 5 选 1，正文直接抄。

**3. 安全卫士**
内置小红书敏感词清单（500+ 违禁词 + 替换对照），发布前自动扫描，避免限流、删笔记甚至封号。

## 🏃 快速开始

### 前置条件

- [Hermes Agent](https://github.com/NousResearch/hermes-agent) 已安装
- 可选：Midjourney / Stable Diffusion / DALL·E（配图生成）

### 安装

```bash
# 1. 克隆仓库
git clone https://github.com/buguanhuayue/xiaohongshu-content-factory.git

# 2. 复制 skill 到 Hermes 技能目录
cp -r xiaohongshu-content-factory ~/.hermes/skills/

# 3. 重启 Hermes Agent 或开启新会话
```

### 使用

直接在对话中触发：

```
帮我做一个小红书笔记，主题是早秋穿搭
帮我分析最近护肤领域的爆款笔记
帮我生成一篇小红书，选题是空气炸锅食谱，领域是美食
```

## 🔄 工作流

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  选题策划 ──→ 文案撰写 ──→ 配图设计 ──→ 排版优化 ──→ 发布排期  │
│     │            │            │            │            │    │
│  热点追踪     标题×5      封面提示词    敏感词检查    最佳时段  │
│  竞品分析     正文撰写    内页图方案    格式调整     素材包    │
│  选题评估     标签推荐    参数建议      终稿输出     数据追踪  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 第一步：选题策划

告诉我你的赛道（护肤/穿搭/美食/职场/健身/旅行...），我会：
- 搜索当前热点话题
- 拆解 2-3 篇爆款笔记的结构
- 输出 3-5 个备选选题，每个都有爆款潜力评估

**输出示例：**

| 选题 | 目标人群 | 差异化 | 爆款潜力 |
|------|---------|--------|---------|
| 早秋穿搭 10 套 look | 18-30 女性 | 按风格分类 | ⭐⭐⭐⭐⭐ |
| 小个子早秋穿搭 | 155-165 女生 | 身高参考 | ⭐⭐⭐⭐ |
| 通勤早秋穿搭 | 职场女性 | 场合细分 | ⭐⭐⭐⭐ |

### 第二步：文案撰写

选定选题后，我会生成：
- **5 个备选标题**（数字法/痛点法/好奇法/干货法/对比法）
- **300-800 字正文**（短句 + emoji + 互动引导）
- **5-10 个标签**（核心词 + 长尾词 + 热点词）

### 第三步：配图设计

生成图像生成提示词：
- 封面图：MJ/SD 提示词 + 参数（--ar 3:4）
- 内页图：与正文结构匹配的方案
- 文字叠加建议

### 第四步：排版优化

- 段落间距、emoji 使用规范
- 敏感词扫描 + 替换
- 可直接复制到小红书编辑器的终稿

### 第五步：发布排期

- 根据赛道推荐最佳发布时段
- 生成完整的发布素材包（保存为 .md 文件）
- 数据追踪指标建议

## ⚠️ 注意事项

1. **敏感词**：小红书对"最""第一""根治""美白""减肥"等词审核严格，发布前务必对照 [敏感词清单](references/敏感词清单.md) 检查。
2. **图片侵权**：AI 生成图片注意避免真人肖像、品牌 logo。
3. **平台规则**：不要留微信号、二维码、外链，容易被限流。
4. **发布频率**：同一账号每天不超过 3 篇。
5. **人工润色**：生成内容建议加入个人经历，避免被识别为 AI 生成。
